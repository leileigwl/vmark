# Session Handoff（会话交接记录）

- **日期**：2026-11-16

## 本轮已完成事项

1. **编辑区核心交互与格式修复**：
   - 修复 `Cmd+B` / `Cmd+I` 在有选区时通过 `document.execCommand('insertText')` 包裹/剥离，无选区时不插入占位符，右键菜单无选区时自动置灰行内格式项。
   - 表格支持在现有表格内安全插入新表格（自动跳出到下方新段落）、完整右键表格操作及整表删除（`execCommand('delete')` 不残留 `| --- |`）。
   - 1.5 秒停顿静默自动保存 + 切换文章前强制落盘保存，不重扫目录、不重置编辑器撤销栈。
   - Mermaid 单击弹出放大预览、快速双击原位切换为单框代码编辑器；`Cmd+F` 默认纯查找计数与跳转，点击展开替换栏。
2. **侧边栏文件树与拖拽体验**：
   - 支持空白处右键新建文件/文件夹（行内毛玻璃虚化命名框确认创建）、右键重命名/复制/移到废纸篓/在 Finder 中显示、文档列表与文档树切换、正文全文搜索。
   - 支持拖拽文件直接移入目标文件夹或拖回根目录；侧边栏右边缘拖拽采用 60fps 虚影参考线，松手落位。
3. **Bloom 24 套开源主题与全图床配置**：
   - 默认保持 Apple Light，内置全部 24 套 Bloom 主题并 1:1 复刻原版 Typora Bloom 的圆角渐变引用块、H1/H2 底部左端渐变条、圆角卡片表格、1.78 宽松行高与暗色加粗提亮；支持 PicGo-Core / OSS / COS / S3 / GitHub / 七牛云 / SM.MS / Imgur 配置与默认 50% 图片缩放。
4. **高清画布灯箱、顶部 0ms 秒切、原生目录选择与 KaTeX 公式（含 Round 6 精修）**：
   - 单击图片或 Mermaid 流程图直接弹出窗口自适应高清灯箱（支持连续按 **空格键（Space）** 反复开关灯箱不滚屏、灯箱内滚轮缩放、360° 顺时针旋转回正、按 `ESC` 关闭），双击流程图原位改代码，正文内滚轮正常滚动页面；
   - 普通代码块常驻单层可编辑 DOM（首次点击直接落光标，零闪烁、不跳回首行）；表格内粘贴图片不断行并支持按 `Backspace / Delete` 删除图片；暗黑模式 Mermaid 连线标签（是/否/能/不能）深底白字高对比显示；
   - 暗黑模式超链接覆盖为柔和冰蓝 `#78aee8`，右侧边距与滚动条恢复标准小箭头指针，左侧文件栏支持 `Shift` 区间连选 + 右键批量删除。
