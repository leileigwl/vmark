# PRODUCT.md：产品定位与需求边界

## 1. 产品一句话定位

**Vmark（维记）**（`V` = Verified / 图标，`Mark` = Markdown / 书签印记）是一款面向独立博主与技术创作者的 **Local-First（本地优先）桌面端 Markdown 创作与合规多平台分发工作台**，打通：
> **Apple Light / Bloom 沉浸写作（无多余模板） $\rightarrow$ 防盗链图片智能转存 $\rightarrow$ 推送前多平台效果预览 $\rightarrow$ 草稿/直发双模式推送与送达成功检测 $\rightarrow$ 平台草稿反向导入与本地独立管理**。

## 2. 解决的行业核心痛点

1. **工具链割裂**：本地写完 $\rightarrow$ 传图 $\rightarrow$ 切多个后台粘贴 $\rightarrow$ 调格式，耗时繁琐。
2. **防盗链裂图严重**：微信公众号、CSDN、知乎、百家号外链图片极易失效，本地图片必须按目标平台策略转存。
3. **发布前盲发 & 同步卡死无反馈**：不知道在公众号/小红书/Linux.do 渲染成什么样就发出去；或者同步卡在“正在同步”不知道到底有没有进草稿箱。

## 3. 核心功能范围

### MVP（Phase 1：纯正写作 + 全平台预览 + 多模式分发闭环）
- **沉浸式现代极简写作（Apple Light / Bloom 主题，无模板、无多余 AI、无软件自身账号）**：
  - 默认提供精致的 Apple Light 苹果白与 Bloom 护眼主题，仅保留纯净的「新建空白文章」、可收缩「文件树 / 大纲」与「一键 URL 导入」。
- **本地优先（Local-First）与独立草稿管理（Local-First Decoupling）**：
  - 挂载本地文件夹，真实 `.md` 文件 + `assets/` 图片目录全离线可用；
  - **平台草稿箱反向导入**：支持真实打开各平台账号后台，一键将草稿箱与已发布文章拉取到本地，富文本自动转为 Markdown 并将防盗链图片下载存盘至 `./assets/`。
  - **导入后彻底切断云端连接**：本地草稿纯离线独立管理，不维持双向强绑定；云端连接严格收敛为**授权托管**与**单向推送分发**。
- **防盗链图片智能转存管线**：
  - 支持平台私有素材直传（微信公众号素材库、博客园、CSDN、百家号等）或自配 OSS/COS/S3/GitHub 图床，内存替换，绝不污染本地源文件。
- **推送前多平台效果预览（Pre-Publish Preview）**：
  - 在推送前可切换预览各平台真实渲染画面（如微信公众号内联样式效果、Linux.do Discourse 排版、小红书图文预览、CSDN/博客园效果），确认无误再推送。
- **全平台多模式分发与发布成功检测（参考 Wechatsync / 思源 Publisher / 小V猫 / 蚁小二）**：
  - **支持平台矩阵**：**微信公众号（重点）**、**GitHub 静态博客（Hexo/Hugo/VitePress/Astro/自建站一键 Push 触发 CI/CD）**、**百家号**、**CSDN**、**博客园**、**微博（头条文章）**、**Linux.do（Discourse 社区）**、知乎、掘金、B站、抖音、X (Twitter)。
  - **双推送模式**：支持按平台特性选择**「推入草稿箱」**（如公众号、百家号、微博、CSDN）或**「直接发布」**（如 Linux.do 论坛选定板块发帖、博客园直发）。
  - **送达成功二次检测**：推送后校验 `postId` 与 `draftUrl/postUrl`，并在管理台展示直达跳转链接，杜绝假成功。

### P1 演进规划
- **小红书图文笔记迁移**：严格对标小V猫/蚁小二规范（独立浏览器 Profile + 独立网络配置 + 3:4 图文/长文草稿）。

## 4. 明确不做的事（Non-Goals）

- ❌ **绝不做脆弱且强耦合的云端双向同步**：不监听云端覆盖本地，不暗中 PATCH 云端，杜绝内容冲突与数据被云端绑架。
- ❌ **不提供任何内置写作模板或强制模板体系**：尊重创作者自由写作，仅提供空白 Markdown 文档与本地目录管理。
- ❌ **不做软件自身的用户注册与账号体系**：开源工具打开即用。
- ❌ **不强制引入大模型 AI 依赖**：保持纯本地确定性逻辑。
- ❌ 不提供“无脑全网同秒群发刷号”功能，守住合规分发与错峰底线。
