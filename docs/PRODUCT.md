# PRODUCT.md：产品定位与需求边界

## 1. 产品一句话定位

**VCat Publisher Desktop** 是一款面向独立博主与技术创作者的 **Local-First（本地优先）桌面端创作与合规多平台分发工作台**，打通：
> **沉浸式 Typora 级写作（模板+素材） $\rightarrow$ 防盗链图片智能转存 $\rightarrow$ 多平台轻量微调与一键草稿箱推送（含反向导入）**。

## 2. 解决的行业核心痛点

根据 2026 年主流工具（小V猫、蚁小二、Wechatsync、MarkText、思源笔记）调研与社区高频差评，本产品重点攻克四大断层：
1. **工具链割裂**：Typora 写完 $\rightarrow$ PicGo 传图 $\rightarrow$ 浏览器插件同步 $\rightarrow$ 后台逐个修格式，单篇分发耗时 30–60 分钟。
2. **防盗链裂图严重**：CSDN/知乎/微信公众号外链图片经常返回 403/0 字节，本地相对路径图片无法直接跨平台发布。
3. **同质化搬运被限流/封号**：原封不动全网群发触发查重机制，商业工具缺乏内容级平台差异化适配。
4. **同步卡死无反馈**：平台接口一旦变动，工具长期停在“正在同步”无明确错误定位。

## 3. 核心功能范围

### MVP（Phase 1：长文博客与技术社区闭环）
- **沉浸式写作与模板/素材库**：
  - Vditor (`ir` 模式) 还原 Typora 即时渲染体验，极简暖象牙/深炭双主题。
  - 内置标准博客模板（技术方案、周记复盘、开源速览）与自定义素材库（代码块、Callout 提示框、作者引流签名档）。
- **本地优先（Local-First）混合资产管理**：
  - 挂载本地文件夹，真实 `.md` 文件 + `assets/` 图片目录全离线可用；本地 SQLite 仅作为发布状态与元数据索引。
- **防盗链图片智能转存管线**：
  - 分发时内存中克隆副本，自动检测本地图片与防盗链外链，支持**私密直传平台素材库**（如博客园文件）或**自配云图床**（OSS/COS/GitHub/S3），绝不污染本地源文件。
- **极简多平台一键分发 + 轻量手调微窗口（Zero-AI 核心）**：
  - 无需配置任何大模型 AI Key，纯本地确定性引擎开箱即用。
  - 点击分发弹出轻量小窗口：勾选目标平台，可按需展开折叠行手动微调单平台标题/导语/标签（支持平台差异化合规）。
  - **合规底线**：强制默认推送至各平台**草稿箱**，并提供 4 步实时状态日志。
  - 首发适配：**博客园（Cnblogs）**、掘金、知乎、CSDN、自建博客（WordPress/Typecho）。
- **线上文章反向导入**：
  - 输入博客园等平台文章 URL，自动解析正文并将外链图片下载归集至本地 `assets/`，生成标准 `.md`。

### P1 演进规划（后续阶段）
- **小红书图文笔记迁移**：严格对标小V猫/蚁小二规范（独立浏览器 Profile + 独立网络配置 + 长文 AI 切片生成 3:4 卡片图 + 人工确认进草稿）。

## 4. 明确不做的事（Non-Goals）

- ❌ **不做软件自身的用户注册与账号体系**：作为开源桌面工具，打开即用（Local-First），仅在「设置 -> 平台对接」中管理外部发文平台（博客园/掘金等）的本地授权凭据。
- ❌ 不做纯云端 SaaS 文档库（不强制用户把原始文章托管到第三方服务器）。
- ❌ 不提供“一秒无脑全网公开群发/批量刷号”功能（守住合规分发红线，默认进草稿）。
- ❌ 不凭空编写高风控平台（如小红书/抖音）的非法逆向绕过脚本。
