### 2. 掘金分类运行时拉取
- **要做什么**：发布弹窗里掘金的分类列表从掘金实时获取，拿不到时用内置列表。
- **为什么**：掘金调整分类后，内置列表会过时，选了不存在的分类草稿会出错。
- **改哪些文件**：`packages/adapters/src/juejin.ts`（已有 `listCategories()`）、`apps/desktop/src/main/ipc/publish/`、`features/publish-flow/CategoryPicker.tsx`；新增 IPC 通道涉及 `packages/shared`，要先问。
- **先写的失败测试**：IPC 返回新分类时界面显示新分类；IPC 失败时显示内置列表且不挡住发布。
- **做完的标准**：两条测试通过；打开弹窗不会因为拉分类变慢（超时退回内置列表）。
- **需要维护者提供什么**：同意新增 IPC 字段；真机看分类是否和掘金编辑器一致。

- **做完的标准**：测试通过，普通公式大小不变，附卡片截图。
- **需要维护者提供什么**：一篇真实的含长公式文章（可选）。

### 4. 登录顶栏实时跟随主题
- **要做什么**：内置浏览器开着的时候切换应用浅色/深色，登录顶栏立刻变色。

### 5. Windows / Linux 上 Ctrl+S、Ctrl+N 触发两次
- **要做什么**：按一次 Ctrl+S 只保存一次，按一次 Ctrl+N 只新建一个文件。
- **为什么**：菜单快捷键和编辑器快捷键都响应，会新建两个文件或重复保存。
- **改哪些文件**：`apps/desktop/src/main/index.ts`（菜单，注意行数棘轮）、`features/editor-ir/shortcutGuards.ts`。
- **先写的失败测试**：L3 真 Electron 中按一次 Ctrl+S，断言保存只调用一次；Ctrl+N 只新建一个文件。
- **做完的标准**：测试通过，`@smoke` 全过，macOS 的 ⌘S/⌘N 不受影响。
- **需要维护者提供什么**：Windows 真机各按一次。

### 6. 打包版 KaTeX 字体检查
- **要做什么**：确认打包后的应用里公式字体能正常加载（编辑器和卡片都要）。
- **为什么**：开发模式正常不代表打包后正常，字体缺失时公式会变成难看的默认字体。
- **改哪些文件**：新增一个检查脚本（列出打包产物里的 `KaTeX_*` 字体），不改 CI。
- **先写的失败测试**：脚本在缺少字体时报错退出。
- **做完的标准**：脚本能列出字体；维护者真机打开含公式的文档确认。
- **需要维护者提供什么**：在 macOS / Windows 打包一次并打开含公式的文档。

### 10. 凭据加密
- **要做什么**：把图床的 Token、AccessKey/SecretKey 改成用系统钥匙串加密保存。
- **为什么**：现在这些密钥明文存在电脑的配置文件里，别人拿到这个文件就能用你的图床账号。
- **改哪些文件**：`apps/desktop/src/main/ipc/context.ts`、`apps/desktop/src/main/ipc/image-config/index.ts`、新文件 `main/secretStore.ts`。
- **先写的失败测试**：保存含 token 的配置后读磁盘原文，断言不含 token 明文；旧明文配置启动时被迁移为加密。
- **做完的标准**：磁盘上无明文；旧配置自动迁移且其他设置不丢；本机不能加密时只在内存里用并提示；渲染进程只拿到「已设置」状态。
- **需要维护者提供什么**：macOS 首次读钥匙串是否弹窗、Windows 是否正常。

### 11. Vditor 升级修 XSS

- **为什么**：当前 3.11.3 有公开的安全公告（4.0.1 起修复），打开别人给的文档可能中招。
- **改哪些文件**：`apps/desktop/package.json`、`pnpm-lock.yaml`、`apps/desktop/scripts/copy-vditor-assets.mjs`、`features/editor-ir/`。
- **先写的失败测试**：L2 打开公告里的恶意片段，断言脚本没有执行。
- **做完的标准**：XSS 用例通过；`@smoke` 全过；公式、表格、任务列表、代码块渲染不退化。
- **需要维护者提供什么**：真机检查打包版编辑器和预览。

### 12. Shift+Tab 不能反缩进列表
- **要做什么**：列表项里按 Shift+Tab 减少一级缩进。
- **为什么**：现在按了没反应，只能手动删空格。
- **改哪些文件**：`features/editor-ir/shortcutGuards.ts`、`features/editor-ir/index.ts`、`apps/desktop/tests/smoke-integrity-shortcuts.spec.ts`。
- **先写的失败测试**：二级列表项 Shift+Tab 后变为一级，文件其余内容逐字节不变。
- **做完的标准**：测试通过，其他快捷键用例不变。
- **需要维护者提供什么**：macOS / Windows 各按一次。

### 13. 在缩进代码块里编辑会丢整块
- **要做什么**：在 4 空格缩进的代码块里改字后保存，代码块不能消失。
- **为什么**：这是丢用户内容，最高优先级的那类问题。
- **改哪些文件**：「只写回改过的行」逻辑（`features/workspace-tree/`）、`features/editor-ir/index.ts`。
- **先写的失败测试**：`@smoke`——块内第二行末尾输入 `x`，保存，代码块所有行仍在、只多一个 `x`。
- **做完的标准**：测试通过，其余 `@smoke` 全过；**不允许**偷偷把缩进代码块改成 ``` 围栏格式。第 1 步计划里要给至少两个方案让维护者选。
- **需要维护者提供什么**：选方案。

### 14. 切换文件时最后输入是否落盘
- **要做什么**：在 A 文件打字后立刻点开 B 文件，A 的最后输入不能丢。
- **为什么**：关窗/退出已经会先保存，但切换文件还没确认。
- **改哪些文件**：`features/workspace-tree/index.ts`、`apps/desktop/src/main/editorSafety.ts`。
- **先写的失败测试**：`@smoke` L2——A 中输入后 100ms 内点 B，读 A 的磁盘内容，断言包含输入。
- **做完的标准**：测试通过，不会把 A 的内容写进 B。
- **需要维护者提供什么**：无。
