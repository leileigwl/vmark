Electron 沙箱与多平台草稿分发架构

这是一份完全基于 Typora 原版白色（github.css） 规范的沉浸式写作画布。左侧文件树与模板库可随时一键收缩隐藏，日常写作完全离线，图片自动保存在本地 assets/ 目录。

提示：点击右上角「合并分发」按钮时，系统才会弹出轻量小窗；原文件在本地保持纯正的相对路径，不会被强行改写为外部链接。

核心分发 4 步中间管线

为了彻底解决“同步卡死无报错”与“跨平台防盗链裂图”，每次推送草稿箱都会经过主进程的严格流水线：

// 分发引擎内部 4 步状态流转（Zero-AI 确定性管线）
1. PRECHECK        -> 校验独立 Partition Cookie 或 MetaWeblog 鉴权
2. IMAGE_TRANSFER  -> 查 SQLite image_cache 缓存，未命中则上传平台图床
3. TRANSFORM       -> 应用平台微调标题/标签，编译目标 HTML / Markdown
4. DRAFT_PUSH      -> 调用草稿箱接口，写入 sync_records 状态表
