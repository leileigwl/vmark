Electron 沙箱与多平台分发架构

这是完全对标 Typora 原版白色（github.css） 的纯净自由写作区。去除了多余写作模板，完全本地离线优先，粘贴截图自动落盘至 assets/ 目录。

在推送前，请点击顶部「推送前全平台预览」核对微信公众号内联排版、Linux.do 论坛排版等最终呈现效果。

5 步送达检测管线

不仅推入草稿箱，第 5 步还会对返回 ID 与直达链接进行二次回查确认，彻底杜绝“假成功”：

1. PRECHECK        -> 校验各平台沙箱 Cookie / MetaWeblog / Discourse Session
2. IMAGE_TRANSFER  -> 命中 image_cache 则复用，未命中则直传公众号/CSDN/博客园图床
3. TRANSFORM       -> 公众号内联 CSS 编译 / Linux.do Discourse 格式转换
4. PUSH            -> 按平台模式执行「草稿箱保存」或「直接发布」
5. VERIFY_DELIVERY -> 校验 postId & draftUrl，确认送达后回写 SQLite 管理台
📱 微信公众号预览（自动应用 Inline CSS · 宽度 460px · 微信素材图床转存就绪）
