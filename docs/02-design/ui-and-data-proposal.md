## 一、侧边栏文件树：左右键 / 右键操作与面板适配（对应截图 1 & 截图 2）

### 1. 文件列表右键上下文菜单（Context Menu）
在侧边栏任意 `.md` 文件或文件夹上右键，弹出原生感轻量化菜单：
- **打开 / 在新窗口打开**（当前已支持点击切换）
- **重命名**（支持行内直接编辑文件名，`Enter` 确认、`Esc` 取消，自动保留/补全 `.md` 后缀，防重名校验）
- **复制文件 / 复制相对路径**
- **在 Finder 中显示**（调用已有 `showInFinder(relativePath)`）
- **移到废纸篓 / 删除**（调用 Electron `shell.trashItem` 优先安全删除，带二次确认）
- **新建文件 / 新建文件夹**（在当前目录或选中文件夹内创建，沿用 `Untitled.md` → `Untitled 2.md` 顺序命名）

### 2. 键盘导航（上下左右键 + 快捷键）
当焦点位于侧边栏文件树时：
- `↑` / `↓`：上下移动高亮选中项
- `→` / `←`：
  - 若为文件夹：`→` 展开目录，`←` 折叠目录（若已折叠则跳回父目录）
  - 若为文件：`→` 或 `Enter` 切入右侧正文编辑区
- `Enter`（或 `F2`）：触发当前选中文件行内重命名（可配置开关，或采用 `Cmd+R` / `Enter`）
- `Backspace` / `Delete`：触发安全移至废纸篓确认

### 3. 侧边栏宽度调节 & 左下角 `操作` 弹出面板（对应截图 2）
- **侧边栏拖拽调宽**：在侧边栏右边界增加 `4px` 隐形拖拽热区（`200px` ~ `420px`，默认 `240px`），拖拽时内部文件名自动 `truncate`，底部栏与顶部栏自适应不挤压。
- **左下角 `操作` 弹出面板精调**：
  - 修正底部 `+ | 工作区名称 | ⋮ | 折叠` 的水平对齐与点击热区，避免弹出菜单与底栏按钮遮挡/错位。
  - **右下角/面板角落锁定（Pin）**：为“大纲 / 操作面板 / 浮窗”增加 **图钉锁定按钮**（锁定后切换目录或失焦不自动收起，未锁定时点击外部自动关闭），并缩小面板冗余留白，使紧凑度贴合原生桌面端。

## 三、关于“观测当前帖子数据”（阅读量 / 点赞 / 评论）的可行性说明

### 1. 当前状态（Phase 1）
目前 `@vcat/adapters`（见 `packages/adapters/src/index.ts`）仅定义了 **分发链路接口**：
- `checkAuth()`（授权检测）
- `uploadImage()`（图床上传）
- `push()`（发布/草稿推送）
- `verifyDelivery()`（送达校验）

因此**现阶段除平台授权状态外，暂未接入各平台帖子阅读量/点赞/评论等回流数据**。

### 2. 后续扩展（Phase 2 / Phase 3 可行方案）
若后续需要观测“当前文章在各已发布平台的数据”，可在不引入重型爬虫的前提下按平台差异分两级支持：
- **A 级（开放接口直接读取，低风险）**：
  - **Linux.do (Discourse)**：已有 `postId` / `topicId`，可直接调用 `/t/{topic_id}.json` 获取 `views`（阅读）、`like_count`（点赞）、`posts_count`（回复数）。
  - **博客园 (Cnblogs)**：可通过 MetaWeblog / 文章页公开元数据读取基础阅读数与评论数。
  - **GitHub 静态博客**：可读取最新 GitHub Actions 部署状态与页面 URL 可达性（200 OK）。
- **B 级（登录态受限平台，按需手动刷新）**：
  - **微信公众号 / 掘金 / CSDN / 知乎**：需借助已有 `partition_cookie` 登录态，在用户点击“刷新数据”时请求平台创作者后台列表接口提取阅读/点赞/评论，**不建议后台高频轮询**以免触发风控。
