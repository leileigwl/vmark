## 四、代码块物理隔离与三反引号展开

```ts
interface ArticleCheckpoint {
  round: number;
  title: string;
  verified: boolean;
}

export function verifyArticle(item: ArticleCheckpoint): string {
  return `${item.round}: ${item.title} -> ${item.verified}`;
}
```

验证要点：
- 在空白行连续敲击 3 次 `` ` ``，展开为标准代码块且上方零残留反引号；
- 语言框选完语言按 `Enter` 直接落入正文第 1 行；
- 代码块内全选删除（`Cmd+A` + `Backspace`/`Delete`）仅清空代码正文，语言标签与 mac 圆点完好无损；
- 在代码块首行行首按 `Backspace` 或末行行尾按 `Delete` 不会撕裂代码块；仅当正文原本已为空时再按 `Backspace` 才移除整块。
