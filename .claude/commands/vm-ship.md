---
description: 审核通过后开 draft PR（中文正文、贴命令输出、截图）
argument-hint: [PR 标题]
---
前提：最近一次 `/vm-review` 没有 🔴。否则先停下。

1. 推送当前分支，开 **draft** PR，目标分支 `preview/latest`。绝不标 ready、不合并、不评论别人的 PR。
2. PR 标题：$ARGUMENTS（没给就用中文概括）。
3. PR 正文固定四段（中文）：

```
## 改了什么
## 怎么验证的
（贴命令输出：改前失败 → 改后通过；写明验证层级 node / L2 / L3）
## 怎么回退
## 需要维护者真机确认
```

4. 有界面改动时加 `## 截图`：浅色、深色各一张，改前改后都要。
5. 可评审 diff 超过 600 行时，正文第一行写 `size-exempt: <理由>`。
6. 把 `/vm-review` 报告里的 🟡、🟣 写进正文末尾「已知问题」。
7. 输出 PR 链接，并运行 `/vm-handoff`。
