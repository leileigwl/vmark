# 一个人的效率系统：三年实践复盘

> 工具不重要，重要的是你每天都回到同一个地方。

三年前我开始认真整理自己的工作方式。最开始只是想少忘几件事，后来慢慢变成了一整套系统。这篇文章把它拆开讲清楚，适合刚开始搭建个人系统的朋友。

## 一、收集：所有东西先进收件箱

脑子是用来思考的，不是用来记事的。任何念头、任务、链接，第一时间丢进**同一个收件箱**。每天晚上花十分钟清空它，决定每一条的去处。

- 手机上用快捷指令一键记录
- 电脑上用全局快捷键呼出输入框
- 纸质笔记本只记灵感，每周誊抄一次

## 二、整理：只保留三个清单

| 清单 | 放什么 | 多久看一次 |
| --- | --- | --- |
| 今天 | 必须今天完成的事 | 每小时 |
| 本周 | 本周想推进的事 | 每天早上 |
| 将来 | 也许某天会做的事 | 每周日 |

清单越少，越容易坚持。我试过十几个分类，最后都回到了这三个。==少即是多==，这句话在效率系统里尤其成立。

## 三、执行：用代码自动化重复劳动

每周日的复盘数据，我用一个小脚本自动统计：

```python
import datetime

def weekly_review(tasks):
    today = datetime.date.today()
    done = [t for t in tasks if t.done]
    rate = len(done) / max(1, len(tasks))
    print(f"{today}: 完成 {len(done)} / {len(tasks)}，完成率 {rate:.0%}")
    return done
```

## 四、复盘：每周日晚上的一小时

每周日晚上，我会回顾这一周：哪些事情推进了，哪些一直拖着，为什么拖着。复盘不是为了自责，而是为了下周更轻松。坚持三年下来，最大的收获不是效率提高了多少，而是心里踏实了。焦虑往往来自不确定，而系统给了我确定感。

1. 先看日历，确认下周的硬性安排
2. 再看“将来”清单，挑一两件提到本周
3. 最后写三句话，记录这周的感受

> 先完成，再完美。这是我贴在显示器上的一句话。

$$
专注时间 = 总时长 - 被打断次数 \times 23 分钟
$$
