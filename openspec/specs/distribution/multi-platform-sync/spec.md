# distribution/multi-platform-sync Specification

## Purpose
提供多平台独立沙箱会话管理、草稿箱一键批量分发以及线上文章反向导入引擎，首发覆盖博客园（Cnblogs）、掘金、知乎、CSDN与自建博客系统，并为后续小红书卡片分发预留适配器通道。

## Requirements

### Requirement: 独立 Session 沙箱登录与状态保活
系统 SHALL 为每个接入平台分配隔离的 Electron Partition 会话沙箱，允许用户安全扫码或账号登录，并本地加密持久化 Cookie 与鉴权 Token。

#### Scenario: 登录博客园并保持会话
- **WHEN** 用户在“平台管理”中打开博客园登录弹窗并完成登录
- **THEN** 系统提取博客园 Session 与验证凭据，本地加密存储，并在分发面板上显示为“在线”状态

### Requirement: 博客园及主流技术社区一键草稿推送
系统 SHALL 提供统一的多平台发布适配器（Adapter Pattern），将本地 Markdown 转换为各平台支持的草稿格式，并调用官方 Web 后台接口保存至草稿箱。

#### Scenario: 批量同步至博客园与掘金草稿箱
- **WHEN** 用户选择当前文章并勾选“博客园”与“掘金”，点击“一键分发”
- **THEN** 系统按平台顺序执行图片转存并推送草稿，在 10 秒内返回两个平台的草稿创建成功结果与草稿编辑直达链接

#### Scenario: 平台鉴权过期自动提醒
- **WHEN** 某一平台的登录态已失效导致接口返回 401 或鉴权错误
- **THEN** 系统捕获错误、标记该平台为“需重新登录”，并弹出快捷重新登录提示，不影响其他平台的正常分发

### Requirement: 线上文章一键反向导入本地
系统 SHALL 支持输入主流平台（如博客园已有文章）的文章 URL，自动解析 HTML 结构并将其转换为本地标准的 Markdown 文档和本地配图。

#### Scenario: 输入博客园文章链接导入
- **WHEN** 用户在导入面板中粘贴某篇博客园公开文章 URL 并点击“开始导入”
- **THEN** 系统解析标题、发布时间与正文，将文中外部图片下载至本地 `assets/` 目录，并在当前工作区生成对应的 `.md` 文件
