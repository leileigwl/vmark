# Spec Delta

## Purpose

构建本地优先的图片资产管理与防盗链转存管线，支持写作期间本地离线预览，分发时自动将图片上传至目标平台素材库或自建通用图床，杜绝外链跨域防盗链导致的图片损坏。

## ADDED Requirements

### Requirement: 本地图片资产归集与安全隔离
系统 SHALL 默认将文章内粘贴或拖拽的图片存储在当前工作区对应的 `assets/` 相对路径目录下，保证全离线状态下图片正常渲染。

#### Scenario: 离线插入图片无损持久化
- **WHEN** 用户在无网络连接状态下截图粘贴到编辑器
- **THEN** 图片被保存为本地 `assets/<timestamp>-<hash>.png`，编辑器使用相对路径完成无损显示

### Requirement: 分发时防盗链检测与智能转存
系统 SHALL 在执行文章分发前分析全文图片引用，识别本地图片与受防盗链保护的外链，并按目标平台策略执行自动转存上传。

#### Scenario: 自动转存至博客园专属图床
- **WHEN** 用户向博客园分发包含本地 `assets/demo.png` 的文章
- **THEN** 分发引擎调用博客园文件上传接口将图片上传为博客园 CDN 资源，并仅在发送至博客园的草稿副本中替换该图片 URL

#### Scenario: 保持本地源文件路径不变
- **WHEN** 图片转存成功并推送到线上平台
- **THEN** 本地 Markdown 文件仍然保持原有的本地相对路径引用，不强行改为外部 CDN 链接

### Requirement: 通用云图床与 PicGo 生态接入
系统 SHALL 支持用户配置阿里云 OSS、腾讯云 COS、GitHub、S3 兼容图床凭证，并支持一键将本地图片批量托管至公网 CDN。

#### Scenario: 使用用户自配阿里云 OSS 上传
- **WHEN** 用户配置了有效的 OSS 凭据并在发布时勾选“优先托管至私有 OSS”
- **THEN** 引擎自动将未上传图片推送到指定的 OSS Bucket 并生成具备签名或自定义域名的访问链接
