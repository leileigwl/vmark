# Spec Delta

## Purpose

提供本地优先的工作区目录挂载与文件管理能力，基于真实本地 Markdown 目录结合轻量 SQLite 索引，维护文章状态、同步记录与历史版本，保证用户数据的透明性与持久性。

## ADDED Requirements

### Requirement: 本地工作区目录挂载与扫描
系统 SHALL 支持用户选择并打开本地任意文件夹作为写作工作区，并自动建立文件树结构与增量监听。

#### Scenario: 打开本地文件夹成功
- **WHEN** 用户点击“打开工作区”并选取本地一个包含 Markdown 文件的目录
- **THEN** 界面左侧展示完整的文件目录树，并自动过滤隐藏文件与非 Markdown 资源

#### Scenario: 外部文件变更热感知
- **WHEN** 用户在外部编辑器（如 Typora 或 VS Code）修改或新增 `.md` 文件
- **THEN** 系统文件监听服务在 500ms 内自动刷新工作区文件树与当前活动文档视图

### Requirement: SQLite 混合元数据索引与状态管理
系统 SHALL 在本地应用程序目录中维护 SQLite 数据库，用于索引工作区文件路径、平台同步状态、草稿发布记录以及关联标签。

#### Scenario: 首次挂载建立索引
- **WHEN** 用户挂载新工作区目录
- **THEN** 系统自动扫描并在 SQLite 中建立文章文件索引，若已存在历史同步记录则自动关联

#### Scenario: 保持 Markdown 文件纯净
- **WHEN** 系统向 SQLite 写入文章的各平台发布状态或统计元数据
- **THEN** 用户的本地 `.md` 文件正文内容与结构不会被强行插入任何侵入性私有标记
