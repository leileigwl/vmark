# Spec Delta

## Purpose

提供基于 Vditor 即时渲染技术的沉浸式富文本 Markdown 写作环境，完整还原类似 Typora 的即时排版体验，并提供开箱即用的技术博客模板库与灵活的快捷素材插槽。

## ADDED Requirements

### Requirement: 类 Typora 即时渲染 Markdown 核心
系统 SHALL 提供无缝的即时渲染（IR 模式）编辑能力，用户输入 Markdown 标记后光标离开即刻转为富文本排版，支持代码块高亮、数学公式与表格。

#### Scenario: 实时富文本渲染
- **WHEN** 用户在编辑器中键入二级标题 `## 核心架构设计` 并回车
- **THEN** 编辑器立即将其渲染为 H2 富文本样式，光标进入该行时才显示源码标记

#### Scenario: 快捷贴图自动关联
- **WHEN** 用户从剪贴板粘贴图片或拖入图片文件至编辑区
- **THEN** 系统自动将图片保存至本地 `assets/` 目录，并在文档中插入相对路径 Markdown 图片语法

### Requirement: 基础博客模板库
系统 SHALL 提供多套标准技术写作模板，支持一键基于模板创建新文章并填充骨架内容。

#### Scenario: 从模板创建技术文章
- **WHEN** 用户在新建文章菜单中选择“技术方案设计模板”
- **THEN** 系统在工作区自动生成包含背景、架构图占位、核心接口与风险评估的初始文章

### Requirement: 素材库与快速插槽调用
系统 SHALL 提供快捷素材库抽屉，允许用户保存与一键插入预定义的代码片段、高亮引用块（Callout）以及文末作者签名档。

#### Scenario: 插入引流签名档素材
- **WHEN** 用户在文章末尾点击素材库并选择“公众号与博客园签名卡片”
- **THEN** 对应 HTML/Markdown 样式的素材块直接注入到光标所在位置
